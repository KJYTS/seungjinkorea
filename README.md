# (주)승진상사

HTML과 CSS만으로 만든 반응형 메인 화면입니다. `index.html`을 브라우저로 열면 됩니다. 빌드나 패키지 설치, JavaScript는 필요하지 않습니다.

선택적으로 `npm run dev` 또는 `python3 -m http.server 3000`으로 실행할 수 있습니다.

화면에는 제공된 메뉴, 인사말, 소개 원문 네 문단, 임직원 서명만 표시합니다. 메뉴는 본문 관련 문단으로 이동합니다. 별도 제품 페이지나 고객센터 기능은 추가하지 않았습니다.

로고와 회사 사진은 사용자가 업로드한 원본을 사용합니다.

- 로고: `assets/승진로고.png`
- 회사 사진: `assets/센터엠 사진.jpg`

모바일에서는 회사 사진의 원본 비율을 유지합니다. 이미지 파일명은 업로드된 이름을 그대로 유지합니다.
